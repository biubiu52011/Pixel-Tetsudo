# Pixel Tetsudo

Pixel Tetsudo is a railway map web application with real-time train tracking and route planning features.

## Features
- Route search between stations
- Real-time train status display
- Train location mapping
- Multi-language support (ja, zh, ko, en)
- Historical status tracking

## Setup
1. Install dependencies: `npm install`
2. Build project: `npm run build`
3. Start server: `npm start`
