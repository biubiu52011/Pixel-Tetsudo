## Changes Summary

### P0 FIX: js/search-ui.js — String Corruption Recovery
Root cause: RC-1 commit (63b388d) introduced backslash-corrupted string literals
during a rewrite of the renderResults() journey card function. The corruption
affected 8 lines with three distinct patterns:

1. **Language fallback** (L214): `|| \ ja\;` -> `|| 'ja';`
   - Tab char (0x09) replaced quote before 'ja', backslash before semicolon
   - Fixed by restoring proper single-quoted string literal

2. **String comparison** (L218, L235): `=== 	ransfer\)` -> `=== 'transfer')`
   - Tab char before 'transfer', backslash before ')'
   - This caused transfer detection to NEVER work (comparison always false)
   - Fixed by restoring proper single-quoted string literal

3. **HTML class attributes** (L219, L220, L248-L251):
   - `class=\search-result journey-card\` -> `class="search-result journey-card"`
   - `class=\journey-header\` -> `class="journey-header"`
   - `class=\journey-seg` -> `class="journey-seg"` + missing closing quote
   - `style=order-left-color:` -> `style="border-left-color:"` (backspace 0x08)
   - `class=\journey-seg-name\` -> `class="journey-seg-name"`
   - `class=\journey-seg-route\` -> `class="journey-seg-route"`
   - `class=\journey-seg-duration\` -> `class="journey-seg-duration"`

User impact before fix:
  - Journey card rendered with NO visual styling (CSS classes broken)
  - Transfer count always 0 (comparison never matched)
  - Transfer stations never displayed
  - Line segment colors never applied
  - Route search effectively broken for multi-line routes

### P2 FIX: js/data-state.js:218 — Operator ID Leak
  - Changed: `escapeHtml(op)` -> `escapeHtml(tOp(op))`
  - Operator group titles now show translated names instead of raw IDs

### P2 FIX: js/trains-page.js:242 — Fallback to Raw ID
  - Changed: `: fusedLine.id` -> `: (fusedLine.nameEn || fusedLine.nameJa || lineId)`
  - When RailwayDB unavailable, falls back to human-readable name instead of line_id

### P2 FIX: js/translations.js — Missing op.* i18n Keys
  - Added 21 operator x 4 language = 84 new translation keys
  - Covers all operators present in railway_data.json canonical data
  - Languages: EN (English), JA (Japanese), ZH (Chinese), KO (Korean)
