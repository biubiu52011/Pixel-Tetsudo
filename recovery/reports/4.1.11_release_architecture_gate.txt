## 3. Entry Point Map for New Developer

```
New developer arrives → reads pages/home.html
    ↓
Sees script load order:
  1. data/core/db-loader.js       → RailwayDB (canonical data + resolveLineName/resolveStationName)
  2. js/translations.js            → window.t (i18n)
  3. js/common.js                  → helpers
  4. js/lang-init.js               → window.tOp, window.currentLang
  5. js/data-state.js              → window.DataState (renderList, renderCard)
  6. js/search-ui.js               → Route search UI (uses RailwayDB)
  7. js/realtime-view.js           → Realtime UI (uses RailwayDB + DataState)
  8. js/trains-page.js             → Trains listing (uses RailwayDB + DataState)
  9. js/trains-detail.js           → Line detail (uses RailwayDB)
  10. js/history.js                → Search history (uses RailwayDB)
```

**Clear entry points:**
- Add new line display logic → `js/data-state.js` → `renderCard()`
- Add new page → follow `pages/trains.html` script load pattern
- Add new translation → `js/translations.js`
- Modify line data → `data/core/railway_data.json` (LOCKED — note this!)
