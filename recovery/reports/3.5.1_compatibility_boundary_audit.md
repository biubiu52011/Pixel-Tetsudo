## Architecture Preserved

```
DataFusion → UNIFIED_LINES (static data source for realtime fusion)
DataLayer → RailwayDB (primary) → UNIFIED_LINES (fallback)
Business layers → DataLayer (RailwayDB-first) → UNIFIED_LINES (fallback)
```

## Key Finding

**DataFusion's 10 UNIFIED_LINES references are essential** — they are NOT compatibility fallbacks but the PRIMARY data path for the realtime system. DataFusion reads static line metadata from UNIFIED_LINES, merges it with ODPT realtime delay data, and produces fused output that downstream consumers (RealtimeView, DataState) use.

The remaining 35 RETAIN entries are all RailwayDB/DataLayer compat fallbacks that only activate when RailwayDB is not yet loaded. These can be safely deferred for removal in a future cleanup task.
